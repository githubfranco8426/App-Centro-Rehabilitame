# App de reservas — Centro de Rehabilitación

App web para que pacientes reserven horas con Kinesiólogo, Fonoaudiólogo y Terapeuta Ocupacional, con panel de administrador para ver y gestionar toda la agenda.

## Estado del proyecto

Aún no se ha generado el código (proyecto Next.js pendiente de crear). El plan completo de arquitectura está en [`docs/plan.md`](docs/plan.md).

Pendiente antes de continuar el desarrollo en cualquier equipo:
- Instalar [Node.js LTS](https://nodejs.org/) (requerido para Next.js).
- Crear el proyecto en Supabase.
- Crear cuenta en [Resend](https://resend.com/) para el envío de emails.

## Stack

Next.js (App Router, TypeScript) + Tailwind CSS + shadcn/ui + Supabase (Postgres/Auth/RLS) + Resend, desplegado en Vercel.
